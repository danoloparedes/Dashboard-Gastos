# Repository notes for agents

- Two backends implement the same data flow: `api/` is Vercel/PostgreSQL; `backend/api_server.py` + `backend/voice_server.py` are local/Raspberry/SQLite. Changes to transaction endpoints, validation, authentication or Sheets sync usually need both implementations. The Vue app calls `/api` in either environment; Vite proxies `/api/auth` and `/api/voice` to Python port 8001, other `/api` paths to port 8000.
- `GET /api/transactions` is public; mutations require an assistant session and `X-Gastos-Request: 1`. Preserve the existing session/origin checks in `api/_lib/auth.js` and `backend/assistant_auth.py` when adding endpoints. Voice instructions/reference are shared via `shared/`; `vercel.json` includes them in voice functions.
- Google Sheets imports into SQL; manual dashboard changes are SQL-only. Sheet row IDs are positional (`worksheet:row`): `sheet_protections` prevents subsequent imports from overwriting edits or recreating deletions *while row positions stay fixed*. Inserting/deleting/reordering rows in Sheets can associate protections with the wrong movement; changing this requires stable source IDs. Keep `api/_lib/database.js`, `backend/sync/db.py` and `backend/sync/schema.sql` aligned when changing sync behavior. The Windows launcher and Raspberry startup script both attempt a Sheets sync on startup.
- Voice saves are SQL-only (`api/voice/save.js` / `backend/voice_pipeline.py`); do not reintroduce Sheets writes through the old `persist_target` field. Speech and extraction instructions are shared in `shared/expense-reference.json` and `shared/expense-instructions.txt` (no historical dates or amounts in prompts). Keep `Hogar` suggestions contextual, not retroactive.
- Shared UI tokens live at the top of `src/style.css`; chart-specific rendering lives in the two `src/components/charts/` SFCs. Keep chart amounts exact in their keyboard/touch readout; use `src/data/transactions.js` for CLP display formatting. No charting library is installed.
- Windows development: `run_dashboard.bat` starts sync, both Python APIs and Vite; it **kills existing listeners on ports 8000/8001**, so do not run it if those processes must be preserved. For independent frontend development use `npm.cmd run dev` (Python APIs are still required for proxied calls). Python reads `backend/.env`; Vercel reads server-side environment variables. Never use `VITE_` for server secrets.
- Verification from the repo root: `npm.cmd test` (all Node tests), `npm.cmd run build`, `.\.venv\Scripts\python.exe -m unittest discover -s backend -p 'test_*.py'` on Windows. Focused: `node --test tests/transactions.test.js`; `.\.venv\Scripts\python.exe -m unittest discover -s backend -p 'test_transaction_sync.py'`. The system Python may lack backend dependencies; install `backend/requirements.txt` in the venv. There is no lint/typecheck script in `package.json`.
